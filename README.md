## Example Project for the CollaboratoR R package

This is an fictitious project used as an example for working 
with the [CollaboratoR R package](https://ibeem-msu.github.io/CollaboratoR/index.html), 
as described in the vignette 
[CollaboratoR Example](https://ibeem-msu.github.io/CollaboratoR/articles/collaborator_example.html)

It is primarily didactive but you may download/clone those repository and move to your own 
github account for running through the tutorial above. 

The example `.Renviron` file may be helpful as the CollaboratoR workflow
requires keys, ids, and points to file, as explained in the vignette above.

Package authors follow the Ecological Data Initiative's (EDI) 
[Data Preparation and Processing Levels](https://edirepository.org/resources/cleaning-data-and-quality-control#Data-processing-levels)

![EDI processing levels ](https://edirepository.org/static/images/data-processing-levels.png)

Data entered and then Validated is "Level 0" as it may have have been checked but
no othe operations have been done.  Once aggregated and summarize it moves to Level 1. 

The "L0" folder in this repository represents the location of our 'raw' (check but not processed)
data. 

In addition to validating the structure of the files and the values within the
constraints. we've added an exploratory analysis
